# 干活细则索引（memory）

> 本目录是 `AGENTS.md` 的「细则侧」。`AGENTS.md` 每轮自动加载，只放红线与速查；
> 这里放**展开后的完整规则**，碰对应场景再读，不要通读。

## 什么时候读哪份

| 场景                                                       | 读这份                                             |
| ---------------------------------------------------------- | -------------------------------------------------- |
| 要改代码 / 提方案 / 跟用户确认 / 写回复                    | [`collaboration.md`](./collaboration.md)           |
| 搜代码、读模块、定改动范围、用工具、派子 Agent、落临时文件 | [`code-and-search.md`](./code-and-search.md)       |
| 动界面、样式、按钮、弹窗、图标                             | [`ui-rules.md`](./ui-rules.md)                     |
| 跑测试、验收、写 changelog、提交、发布                     | [`verify-and-release.md`](./verify-and-release.md) |

## 维护规则

- 本目录随仓库提交（与 `spec/` 其余文档同等待遇）。
- 规则只增不删；确需废止的条目改成「已废止：原因」保留一行，别直接抹掉。
- 不写历史沿革与个人原话，**只写结论与判据**。
- 新增文件时同步更新上面的表格。
