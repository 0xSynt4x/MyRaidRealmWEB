<地图地点规则>
用途:
  - 这是独立的「地图地点」维护环节，不是剧情回合，与主线变量无关
  - 你只负责维护一棵地点层级树；不要输出剧情、不要改动任何其它数据

层级（固定六档，不得新增、不得改名）:
  1. 世界 —— 整棵树的根，有且仅有一个（整个世界 / 位面 / 星球）
  2. 区域 —— 世界下的大范围地理单元（省 / 州 / 大陆 / 星区 / 国度）
  3. 城市 —— 聚居地或据点（城 / 镇 / 村 / 基地 / 站点 / 门派驻地）
  4. 街区 —— 城市内的片区（城区 / 街道群 / 郊野 / 厂区 / 楼层区）
  5. 建筑 —— 可进入的单体建筑或地标（宅院 / 店铺 / 厂房 / 舱室 / 庙宇）
  6. 房间 —— 建筑内部的独立空间（卧室 / 办公室 / 仓库 / 大厅 / 密室）

结构（数组，每项四个字段）:
  名称: string    // 唯一，正式具体；禁止「未命名建筑」「建筑1」这类占位名
  层级: string    // 只能取上面六档之一
  父级: string    // 上一层的「名称」；根节点留空字符串
  描述: string    // 一到两句，写清这里是什么样、有什么

挂载规则:
  - 除根节点外，每项的「父级」必须等于另一个节点的「名称」
  - 只能逐级挂载：世界 → 区域 → 城市 → 街区 → 建筑 → 房间，禁止跨级
  - 「世界」有且仅有一个，且必须是唯一没有父级的节点
  - 已经有根节点时，一律沿用它的名称，不要改名、不要建第二个根
  - 名称全局唯一；同一个地点只留一条，重复的合并成一条，保留信息最完整的那条
  - 父级找不到时，往上补一层再挂，不要留悬空的节点

维护规则:
  - 已经挂载正确的节点原样保留，不要重写、不要改描述
  - 剧情中出现过的地点都要收录；只在台词里被提一句、玩家没去过也没细节的，可以不收
  - 街道名、门牌号不算节点，归到它所在的街区或建筑
  - 房间只在明确进入过、或需要单独记位置时才收录
  - 玩家当前所在的位置必须能在这棵树里找到对应节点

输出:
  - 只输出一个 <地图数据> ... </地图数据> 块，内容是完整的 JSON 数组（含未改动的旧节点）
  - JSON 必须是合法数组：不能有注释、尾逗号，数组外不能有其它文字
</地图地点规则>
