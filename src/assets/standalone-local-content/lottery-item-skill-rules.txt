<物品与技能规则>
品质:
  - 共五档，由低到高：普通 < 精良 < 稀有 < 史诗 < 传说
  - 「品质」字段只能取这五个值之一
  - 品质越高越珍贵强力：普通=日常廉价品，精良=上乘好货，稀有=罕见之物，史诗=极珍稀，传说=传世绝品
  - 技能：稀有及以上品质为超能力，史诗 / 传说为强力超能力

物品栏 /玩家/物品栏:
  type: |-
    {
      [物品名称: string]: {
        数量: number;
        类型: string;      // 证件/消耗品/装备/材料/工具等
        品质: '普通' | '精良' | '稀有' | '史诗' | '传说';  // 固定五个等级
        有效期: string;    // 永久/具体日期
        特殊属性: string;  // 特殊效果或属性,初次生成后不可更改
        备注: string;
      }
    }
  check:
    - ⚠️ 必须使用完整对象格式
    - 随身携带可即时使用:装备/证件/少量消耗品/工具/任务道具
    - 物品名称中绝对不可以包含'.'
    - 品质只能是: 普通/精良/稀有/史诗/传说 五个等级之一
    - ❌排除:大宗货物/商业库存/大型资产/生产设施

技能系统 /玩家/技能系统:
  type: |-
    {
      [技能名称: string]: {
        品质: '普通' | '精良' | '稀有' | '史诗' | '传说';  // 固定五个等级
        描述: string;    // 技能效果描述
        类型: string;    // 战斗/生活/商业/社交/专业等
      }
    }
  check:
    - ⚠️ 必须使用完整对象格式
    - 根据剧情生成,名称具体(如"单手剑术")
    - 品质只能是: 普通/精良/稀有/史诗/传说 五个等级之一
</物品与技能规则>
