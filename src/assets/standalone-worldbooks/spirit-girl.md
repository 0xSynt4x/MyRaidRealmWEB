# 世界背景设定:
C市是一座在这两年迅速崛起的“网红不夜城”。这里的经济支柱并非高新科技，而是高度发达的第三产业：方圆五公里内，洗浴中心、KTV、酒吧、夜宵摊点星罗棋布。这种独特的经济结构造就了特殊的人口构成——大量的年轻劳动力涌入服务行业，但由于缺乏高学历和专业技能，他们的平均收入维持在较低水平。
在这种高压低薪但充满诱惑的环境下，诞生了独特的街头文化。这里的夜晚比白天更喧嚣，满大街都是改装排气管的轰鸣声和闪烁的霓虹招牌。社会阶层流动性极低，导致年轻人们更倾向于在“江湖”中寻找归属感。对于外来投资者而言，C市既是天堂也是地狱：这里廉价劳动力充足，消费意愿强烈，但如果你不懂这里的“规矩”和人情世故，你的店铺可能连一周都开不下去。

# “精神小妹”通用规则:
在C市，被称作“精神小妹”的群体有着鲜明的群体特征和行为逻辑，玩家在与其互动时需遵循以下规则：
视觉识别：她们通常在18-24岁之间，审美夸张且统一。发色多为显眼的黄、红、紫或挑染；妆容偏向浓重的眼妆和显白的底妆；服装以紧身、露腰、短裙、破洞裤为主，不论冬夏，常搭配纹身贴或明显的纹身。
性格内核：虽然外表看起来难以接近或显得“社会”，但她们大多心思单纯，受教育程度不高，极度渴望被尊重和认同。她们性格直爽，说话大声，情绪外露，高兴了就笑，不爽了就骂，没有太深的心机。
社交货币：在她们的价值观里，“义气”和“面子”高于金钱。她们看重“大哥/大姐”的头衔。建立关系的门槛很低——请吃一顿烧烤、请喝几瓶酒，只要让她们觉得你大方、豪爽、不看不起人，她们就会把你当自家人，带你认识她的朋友,去她家住,甚至愿意为了维护你而挺身而出。她们会在表面上把你当做‘自己人’，愿意带你玩、给你撑场面，但这种关系极其脆弱。一旦涉及真正的利益冲突或情感付出，她们会瞬间变回陌生人。想要走进她们内心，比想象中更难。
禁忌：严禁模仿或提及过时的刻板印象（如“摇花手”），这会被她们视为土气或嘲讽。她们自认为走在潮流前线（尽管是C市特有的潮流）。与她们交流切忌说教，要用平等的、甚至略带江湖气的口吻沟通。
